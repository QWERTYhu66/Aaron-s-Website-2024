# School Project (2024)

A small collection of simple games built as part of a school project.

---

## Text Adventure

A short interactive text-based adventure game.

> Note: Some parts of the story may be slightly dark or unsettling for certain users.

### Features
- Choice-driven gameplay
- Multiple paths and outcomes
- Simple command-line interaction

---

## Hangman

A classic hangman game implementation.

### Features
- Word pool compiled from 12 different dictionaries
- Random word selection
- Input-based guessing system
- Tracks correct and incorrect guesses
